## **DIAGRAM 1: HOLISTIC DEVELOPMENT RADAR CHART**

### **Design Specifications:**
```
TIPE: 9-Axis Radar Chart dengan Progressive Layers
FORMAT: Interactive SVG dengan hover effects
DIMENSI: 800x800 pixels
COLOR SCHEME: Gradient berdasarkan development level

VISUAL ELEMENTS:
1. CENTRAL CORE: Personal Development Index (PDI)
   - Circle dengan radius proportional to overall score
   - Color: Gradient gold (#FFD700 → #FFA500)

2. 9 DIMENSION AXES:
   Setiap axis memiliki:
   - Axis label: Nama dimensi (pendek)
   - Scale marks: 0, 20, 40, 60, 80, 100
   - Current score marker
   - Previous score marker (untuk tracking progress)

3. DATA LAYERS:
   Layer 1: Current Assessment (Solid line, warna utama)
   Layer 2: Previous Assessment (Dashed line, warna sekunder)
   Layer 3: Faculty Average (Dotted line, warna netral)
   Layer 4: Development Target (Shaded area, warna transparan)

4. QUADRANT ANALYSIS:
   - Cognitive Quadrant (Kognitif, Manajemen Diri, Finansial)
   - Affective Quadrant (Emosional, Mental, Karakter)
   - Social Quadrant (Spiritual, Lingkungan, Kesehatan Fisik)

5. INTERACTIVE FEATURES:
   - Hover pada axis: Tampilkan detail dimensi
   - Click pada axis: Navigasi ke diagram dimensi spesifik
   - Slider: Bandingkan dengan periode sebelumnya
   - Toggle: Tampilkan/sembunyikan comparison data
```

### **Implementation Code Concept:**

    { axis: "Kesehatan Fisik", color: "#1abc9c" },
    { axis: "Kecerdasan Emosional", color: "#9b59b6" },
    { axis: "Kesehatan Mental", color: "#34495e" },
    { axis: "Karakter & Etika", color: "#f1c40f" },
    { axis: "Spiritual", color: "#e67e22" },
    { axis: "Lingkungan", color: "#27ae60" }
  ],
  
  data: {
    current: [75, 68, 52, 72, 65, 70, 78, 62, 58],
    previous: [70, 65, 48, 68, 62, 65, 75, 58, 54],
    target: [85, 80, 75, 80, 78, 82, 85, 75, 70],
    facultyAverage: [72, 66, 55, 70, 67, 68, 74, 65, 60]
  },
  
  calculateMetrics: function() {
    return {
      overallScore: this.data.current.reduce((a, b) => a + b) / 9,
      balanceIndex: 1 - (this.calculateStdDev(this.data.current) / 100),
      strengths: this.identifyStrengths(this.data.current),
      growthAreas: this.identifyGrowthAreas(this.data.current)
    };
  },
  
  identifyStrengths: function(scores) {
    // Return top 3 dimensions
    const sorted = this.dimensions
      .map((dim, i) => ({ dimension: dim.axis, score: scores[i] }))
      .sort((a, b) => b.score - a.score);
    return sorted.slice(0, 3);
  }
};

      .sum(d => d.value)

      .startAngle(d => d.x0)
      .endAngle(d => d.x1)
      .innerRadius(d => d.y0)
      .outerRadius(d => d.y1);
    
    // Color coding based on depth and value
    const color = d3.scaleOrdinal()
      .range(d3.quantize(d3.interpolateRainbow, this.data.children.length + 1));

## **DIAGRAM 5: EMOTIONAL INTELLIGENCE CIRCUMPLEX**

### **Design Specifications:**
```
TIPE: Circumplex Model dengan Emotion Wheel
FORMAT: Circular emotion mapping dengan quadrants
DIMENSI: 600x600 pixels
COLOR SCHEME: Emotion gradient (Cool → Warm colors)

VISUAL COMPONENTS:

1. EMOTION WHEEL:
   - 8 primary emotions pada circumference
   - Radius: Emotional intensity (0-100)
   - Sectors: Emotional frequency (berapa sering dialami)
   - Color: Hue berdasarkan valence (positive/negative)
   - Saturation: Berdasarkan arousal level

2. QUADRANT ANALYSIS:
   - Quadrant 1: High Positive Affect (Joy, Excitement)
   - Quadrant 2: High Negative Affect (Anger, Anxiety)
   - Quadrant 3: Low Negative Affect (Calm, Peaceful)
   - Quadrant 4: Low Positive Affect (Sad, Depressed)

3. EMOTION TIMELINE:
   - Spiral timeline dari center
   - Each ring: 1 bulan perkembangan emosional
   - Color path: Emotional trajectory over time
   - Key events: Marker untuk significant emotional events

4. SOCIAL CONNECTION MAP:
   - Network diagram untuk hubungan interpersonal
   - Node size: Emotional significance
   - Edge thickness: Relationship strength
   - Edge color: Emotional valence of relationship

INTERACTIVE FEATURES:
- Emotion diary: Log daily emotions
- Pattern recognition: Identify emotional triggers
- Social network analysis: Relationship quality assessment
- Empathy meter: Compare dengan emotional states orang lain
```

### **Implementation Concept:**

      .domain([0, 1])

      .domain([-1, 1])

      emotionRegulation: this.calculateRegulationScore(),

      empathyIndex: this.calculateEmpathyIndex(),
      emotionalBalance: this.calculateBalanceScore()
    };

  calculateBalanceScore: function() {
    const positive = this.data.currentEmotions
      .filter(e => this.getEmotionValence(e.emotion) === 1)
      .reduce((sum, e) => sum + e.intensity, 0);
      
    const negative = this.data.currentEmotions
      .filter(e => this.getEmotionValence(e.emotion) === -1)
      .reduce((sum, e) => sum + e.intensity, 0);
      
    return Math.max(0, 100 - Math.abs(positive - negative));
  }
};
