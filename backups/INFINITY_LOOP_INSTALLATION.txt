## 🎯 WHAT IS INFINITY LOOP ARCHITECTURE?

The system runs **TWO AI PERSONAS** in an endless loop:

1️⃣  THE ARCHITECT (Gemini Persona)
    ├─ Analyzes project state
    ├─ Critiques previous execution
    ├─ Identifies issues (even tiny ones)
    ├─ Creates VERY SPECIFIC implementation tasks
    └─ Returns JSON with next steps

2️⃣  THE EXECUTOR (KIMI K2.5)
    ├─ Reads architect's instructions
    ├─ Writes COMPLETE production code
    ├─ No placeholders, no TODOs
    ├─ Outputs as "### FILE: path/file.tsx"
    └─ Returns full code ready to save

3️⃣  AUTO-SAVE (Fully Automated)
    ├─ Parses "### FILE:" markers
    ├─ Extracts code blocks
    ├─ Saves directly to hard drive
    └─ ⚡ NO PERMISSION PROMPTS - Fully Autonomous!

🔄  REPEAT FOREVER (or until you stop with Ctrl+C)
