## 🆘 QUICK TROUBLESHOOTING

| Problem | Solution |
|---------|----------|
| "API_KEY not set" | `$env:NVIDIA_API_KEY = "your-key"` |
| "No JSON in response" | Script skips, retries next loop (normal) |
| "Files not saved" | Check path in `### FILE:` marker |
| "Hangs on Architect" | Ctrl+C and check API status |
| "Python not found" | Install Python 3.9+ from python.org |
