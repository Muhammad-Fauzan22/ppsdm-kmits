- **Components**:

## 📞 Support & Troubleshooting

### Issue: Courses not showing on website
**Solution**: 
```bash
# 1. Verify server is running
npm run dev

# 2. Check database connection
python scripts/verify_courses.py

# 3. Clear browser cache and refresh
# http://localhost:3000/dashboard/courses
```

### Issue: Vercel deployment not updating
**Solution**:
```bash
# Make sure latest code is pushed
git status
git push origin master

# Check Vercel dashboard for deployment status
# https://vercel.com/projects/ppsdm-kmits
```

### Issue: Missing environment variables
**Solution**:
```bash
# Ensure .env.local contains:
NEXT_PUBLIC_SUPABASE_URL=https://...
SUPABASE_SERVICE_ROLE_KEY=eyJhbGc...

# Restart dev server after updating .env.local
npm run dev
```
