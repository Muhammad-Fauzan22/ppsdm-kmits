### Bagian 1: Konsep Manajemen Kegiatan (15 Menit)

#### 1.1 Apa itu Manajemen Kegiatan?

Manajemen kegiatan adalah proses perencanaan, pengorganisasian, pelaksanaan, dan pengawasan kegiatan organisasi.

```
📸 [Screenshot: Konsep Manajemen Kegiatan]
```

#### 1.2 Siklus Hidup Kegiatan

```
📸 [Diagram: Siklus Hidup Kegiatan]
```

| Tahap | Deskripsi | Status |
|-------|-----------|--------|
| **Perencanaan** | Menentukan tujuan dan rencana | Terjadwal |
| **Persiapan** | Menyiapkan sumber daya | Terjadwal |
| **Pelaksanaan** | Melaksanakan kegiatan | Sedang Berlangsung |
| **Evaluasi** | Menilai hasil kegiatan | Selesai |
| **Dokumentasi** | Mencatat hasil | Selesai |

#### 1.3 Jenis Kegiatan

| Jenis | Contoh | Frekuensi |
|-------|--------|----------|
| **Rapat** | Rapat mingguan, rapat bulanan | Rutin |
| **Workshop** | Workshop keterampilan | Berkala |
| **Seminar** | Seminar topik tertentu | Berkala |
| **Event** | Event tahunan, acara khusus | Tahunan |
| **Pelatihan** | Pelatihan anggota baru | Berkala |
| **Kunjungan** | Kunjungan ke instansi | Sesuai kebutuhan |

#### 1.4 Manfaat Manajemen Kegiatan yang Baik

| Manfaat | Deskripsi |
|---------|-----------|
| **Terorganisir** | Semua kegiatan tercatat dan terjadwal |
| **Transparan** | Semua anggota dapat melihat kegiatan |
| **Efisien** | Menghindari konflik jadwal |
| **Terukur** | Dapat mengevaluasi keberhasilan |
| **Terdokumentasi** | Riwayat kegiatan tersimpan |

### Bagian 3: Menambah Kegiatan Baru (30 Menit)

#### 3.1 Buka Form Tambah Kegiatan

**Langkah 1: Klik Tombol Tambah**
1. Klik tombol **"+ Tambah Kegiatan"** di pojok kanan atas
2. Form tambah kegiatan akan muncul

```
📸 [Screenshot: Tombol Tambah Kegiatan]
```

#### 3.2 Isi Form Kegiatan

**Demo Trainer:**
1. Isi form dengan contoh kegiatan
2. Jelaskan setiap field
3. Simpan kegiatan

**Praktik Peserta:**
Isi form dengan kegiatan nyata organisasi Anda:

| Field | Deskripsi | Contoh | Wajib |
|-------|-----------|--------|-------|
| **Nama Kegiatan** | Judul kegiatan | Rapat Koordinasi Bulanan | ✅ |
| **Kategori** | Jenis kegiatan | Rapat | ✅ |
| **Tanggal** | Tanggal pelaksanaan | 20 Februari 2026 | ✅ |
| **Waktu Mulai** | Jam mulai | 19:00 | ✅ |
| **Waktu Selesai** | Jam selesai | 21:00 | ✅ |
| **Lokasi** | Tempat kegiatan | Ruang Rapat A | ✅ |
| **Deskripsi** | Detail kegiatan | Pembahasan program bulan Maret | ❌ |
| **Penanggung Jawab** | User yang bertanggung jawab | Budi Santoso | ✅ |
| **Anggaran** | Estimasi biaya | Rp 500.000 | ❌ |
| **Kapasitas** | Jumlah peserta maksimal | 20 | ❌ |
| **Syarat Peserta** | Persyaratan untuk ikut | Semua anggota | ❌ |

```
📸 [Screenshot: Form Tambah Kegiatan]
```

#### 3.3 Tips Mengisi Form

**Nama Kegiatan:**
- Gunakan nama yang jelas dan spesifik
- Hindari singkatan yang tidak umum
- Contoh baik: "Rapat Koordinasi Bulanan Februari"
- Contoh kurang baik: "Rapat"

**Deskripsi:**
- Jelaskan tujuan kegiatan
- Sebutkan agenda jika ada
- Berikan informasi penting lainnya

**Anggaran:**
- Isi dengan estimasi realistis
- Sertakan satuan (Rp)
- Contoh: Rp 500.000

**Kapasitas:**
- Tentukan jumlah peserta maksimal
- Pertimbangkan kapasitas ruangan
- Kosongkan jika tidak ada batasan

#### 3.4 Simpan Kegiatan

**Langkah 1: Review Data**
1. Periksa kembali semua data
2. Pastikan tidak ada kesalahan

**Langkah 2: Simpan**
1. Klik tombol **"Simpan"**
2. Tunggu notifikasi **"Kegiatan berhasil ditambahkan"**

```
📸 [Screenshot: Notifikasi Sukses]
```

**Langkah 3: Verifikasi**
1. Kegiatan akan muncul di daftar
2. Cek apakah data sudah benar

### Bagian 5: Mengubah Status Kegiatan (15 Menit)

#### 5.1 Status Kegiatan

| Status | Deskripsi | Kapan Digunakan |
|--------|-----------|-----------------|
| **Terjadwal** | Kegiatan belum dilaksanakan | Saat kegiatan dibuat |
| **Sedang Berlangsung** | Kegiatan sedang berjalan | Saat kegiatan dimulai |
| **Selesai** | Kegiatan telah selesai | Setelah kegiatan selesai |
| **Dibatalkan** | Kegiatan dibatalkan | Jika kegiatan tidak jadi |

#### 5.2 Cara Mengubah Status

**Langkah 1: Buka Kegiatan**
1. Klik kegiatan yang ingin diubah statusnya
2. Detail kegiatan akan muncul

```

```

**Langkah 2: Ubah Status**
1. Cari bagian status
2. Pilih status baru
3. Klik **"Update Status"**

```
📸 [Screenshot: Ubah Status]
```

2. Ubah status dari "Terjadwal" ke "Sedang Berlangsung"

**Praktik Peserta:**

### Bagian 6: Menghapus Kegiatan (10 Menit)

#### 6.1 Cara Menghapus

⚠️ **Peringatan:** Kegiatan yang dihapus tidak dapat dikembalikan.

**Langkah 1: Klik Ikon Hapus**
1. Cari kegiatan yang ingin dihapus
2. Klik ikon 🗑️ pada kegiatan tersebut

```
📸 [Screenshot: Ikon Hapus]
```

**Langkah 2: Konfirmasi**
1. Dialog konfirmasi akan muncul
2. Baca pesan konfirmasi
3. Klik **"Ya, Hapus"**

```
📸 [Screenshot: Konfirmasi Hapus]
```

**Langkah 3: Verifikasi**
1. Kegiatan akan hilang dari daftar
2. Data di Google Sheets akan dihapus

#### 6.2 Kapan Menghapus Kegiatan?

Hapus kegiatan jika:
- Kegiatan dibatalkan dan tidak relevan
- Kegiatan dibuat secara tidak sengaja
- Data kegiatan salah dan tidak bisa diperbaiki

**Alternatif:**
- Gunakan status "Dibatalkan" jika ingin menyimpan riwayat
- Edit kegiatan jika hanya perlu perbaikan

#### 7.1 Cara Export

**Langkah 1: Buka Menu Kegiatan**
1. Klik menu **📅 Kegiatan**

**Langkah 2: Klik Tombol Export**
1. Klik tombol **"Export ke Sheets"** di pojok kanan atas

**Langkah 3: Pilih Periode**
1. Pilih periode yang diinginkan:
   - Semua waktu
   - Bulan ini
   - Bulan lalu
   - Custom range
2. Klik **"Export"**

```
📸 [Screenshot: Pilih Periode Export]
```

**Langkah 4: Verifikasi**
1. Buka Google Sheets
2. Buka sheet `Kegiatan`
3. Pastikan data muncul

```
📸 [Screenshot: Data di Sheets]
```

#### 7.2 Format Data di Sheets

| C | Kategori |
| D | Tanggal |

| G | Lokasi |
| H | Deskripsi |
