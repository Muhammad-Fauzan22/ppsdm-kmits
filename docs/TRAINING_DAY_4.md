## 🎓 Materi Training

### Bagian 1: Konsep Knowledge Sharing (15 Menit)

#### 1.1 Apa itu Knowledge Sharing?

Knowledge sharing adalah proses berbagi pengetahuan, informasi, dan pengalaman antar anggota organisasi untuk meningkatkan kollektif intelligence.

```
📸 [Screenshot: Konsep Knowledge Sharing]
```

#### 1.2 Mengapa Knowledge Sharing Penting?

| Manfaat | Deskripsi |
|---------|-----------|
| **Pembelajaran** | Anggota dapat belajar dari pengalaman orang lain |
| **Inovasi** | Ide baru muncul dari berbagi pengetahuan |
| **Efisiensi** | Menghindari mengulang kesalahan yang sama |
| **Kolaborasi** | Meningkatkan kerja sama tim |
| **Dokumentasi** | Pengetahuan terdokumentasi untuk masa depan |

#### 1.3 Prinsip Knowledge Sharing yang Baik

| Prinsip | Deskripsi |
|---------|-----------|
| **Relevan** | Konten harus relevan dengan kebutuhan organisasi |
| **Jelas** | Penulisan harus mudah dipahami |
| **Terstruktur** | Gunakan struktur yang logis |
| **Dukung Visual** | Gunakan gambar dan diagram jika perlu |
| **Interaktif** | Dorong diskusi dan komentar |

#### 1.4 Jenis Konten Knowledge Sharing

| Jenis | Deskripsi | Contoh |
|------|-----------|--------|
| **Tutorial** | Panduan langkah demi langkah | Cara menggunakan software |
| **Best Practices** | Praktik terbaik | Tips manajemen waktu |
| **Case Study** | Studi kasus nyata | Analisis kegiatan yang sukses |
| **Tips & Tricks** | Tips dan trik | Shortcut keyboard |
| **Review** | Review produk atau tools | Review aplikasi produktivitas |

| Tips | Contoh |

### Bagian 5: Menulis Artikel (30 Menit)

#### 5.1 Buka Editor Artikel

**Langkah 1: Klik "+ Tulis Artikel"**
1. Di menu Knowledge, klik **"+ Tulis Artikel"**
2. Editor artikel akan muncul

```
📸 [Screenshot: Tombol Tulis Artikel]
```

#### 5.2 Isi Form Artikel

**Demo Trainer:**
1. Isi form dengan contoh artikel
2. Jelaskan setiap field
3. Gunakan fitur editor
4. Simpan draft

**Praktik Peserta:**
Isi form dengan artikel nyata:

| Field | Deskripsi | Contoh | Wajib |
|-------|-----------|--------|-------|
| **Judul** | Judul artikel | 5 Tips Manajemen Waktu untuk Mahasiswa | ✅ |
| **Kategori** | Kategori artikel | Manajemen | ✅ |
| **Thumbnail** | Gambar thumbnail | [Upload] | ❌ |
| **Konten** | Isi artikel | [Tulis konten] | ✅ |
| **Tags** | Tag artikel | produktivitas, waktu, mahasiswa | ❌ |

```
📸 [Screenshot: Form Tulis Artikel]
```

#### 5.3 Menggunakan Editor

**Fitur Editor:**

| Fitur | Fungsi | Shortcut |
|-------|--------|----------|
| **Bold** | Teks tebal | Ctrl+B |
| **Italic** | Teks miring | Ctrl+I |
| **Underline** | Teks bergaris bawah | Ctrl+U |
| **Heading** | Judul dan subjudul | - |
| **List** | Daftar | - |
| **Link** | Tambah link | Ctrl+K |
| **Image** | Tambah gambar | - |
| **Quote** | Kutipan | - |

```
📸 [Screenshot: Toolbar Editor]
```

#### 5.4 Tips Menulis Artikel yang Baik

**Judul:**
- Gunakan judul yang menarik
- Jelaskan isi artikel dengan jelas
- Contoh baik: "5 Tips Manajemen Waktu untuk Mahasiswa"
- Contoh kurang baik: "Tips Waktu"

**Struktur:**
- Gunakan heading untuk membagi konten
- Buat paragraf yang pendek
- Gunakan bullet point untuk daftar

**Konten:**
- Tulis dengan bahasa yang mudah dipahami
- Gunakan contoh konkret
- Tambahkan gambar jika perlu

**Tags:**
- Gunakan 3-5 tags
- Pilih tags yang relevan
- Pisahkan dengan koma

#### 5.5 Simpan Draft

Jika belum selesai menulis:

1. Klik **"Simpan Draft"**
2. Artikel akan tersimpan
3. Bisa dilanjutkan nanti

```
📸 [Screenshot: Simpan Draft]
```

#### 5.6 Publikasikan Artikel

**Langkah 1: Review Konten**
1. Periksa kembali konten
2. Pastikan tidak ada kesalahan
3. Cek format dan tata letak

**Langkah 2: Publikasikan**
1. Klik tombol **"Publikasikan"**
2. Tunggu notifikasi **"Artikel berhasil dipublikasikan"**

```
📸 [Screenshot: Tombol Publikasikan]
```

**Langkah 3: Verifikasi**
1. Artikel akan muncul di daftar
2. Semua anggota dapat melihat

#### 5.7 Latihan: Tulis Artikel

**Topik:** Pilih salah satu topik berikut:
1. Tips manajemen waktu
2. Cara berkomunikasi efektif
3. Tips presentasi yang baik
4. Cara mengelola stres
5. Tips belajar efektif

**Struktur Artikel:**
- Judul yang menarik
- Pendahuluan
- 3-5 poin utama
- Kesimpulan
- Tags yang relevan

### Bagian 6: Memberikan Komentar (15 Menit)

#### 6.1 Buka Bagian Komentar

**Langkah 1: Scroll ke Bawah**
1. Buka artikel
2. Scroll ke bagian bawah
3. Bagian komentar akan muncul

```
📸 [Screenshot: Bagian Komentar]
```

#### 6.2 Tulis Komentar

**Langkah 1: Ketik Komentar**
1. Di kotak teks, ketik komentar Anda
2. Gunakan bahasa yang sopan dan konstruktif

```
📸 [Screenshot: Tulis Komentar]
```

**Langkah 2: Kirim Komentar**
1. Klik tombol **"Kirim"**
2. Komentar akan muncul
3. Penulis akan menerima notifikasi

#### 6.3 Tips Komentar yang Baik

| Tips | Contoh |
|------|--------|
| Sopan dan konstruktif | "Artikel yang bagus! Mungkin bisa ditambahkan contoh..." |
| Berikan apresiasi | "Terima kasih atas sharingnya, sangat membantu!" |
| Tanyakan dengan jelas | "Bisa dijelaskan lebih detail tentang poin ke-3?" |
| Hindari kritik pedas | Jangan: "Artikel ini jelek sekali" |
| Berikan saran | "Saran: bisa ditambahkan gambar untuk ilustrasi" |

#### 6.4 Membalas Komentar

**Langkah 1: Klik "Balas"**
1. Cari komentar yang ingin dibalas
2. Klik tombol **"Balas"**

```

**Langkah 2: Tulis Balasan**
1. Ketik balasan Anda
2. Klik **"Kirim"**

```
