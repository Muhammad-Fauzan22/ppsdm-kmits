## 🎓 Materi Training

### Bagian 1: Konsep Transparansi Keuangan (15 Menit)

#### 1.1 Apa itu Transparansi Keuangan?

Transparansi keuangan adalah keterbukaan dalam mengelola dan melaporkan keuangan organisasi kepada semua pihak yang berkepentingan.

```
📸 [Screenshot: Konsep Transparansi Keuangan]
```

#### 1.2 Mengapa Transparansi Keuangan Penting?

| Manfaat | Deskripsi |
|---------|-----------|
| **Kepercayaan** | Meningkatkan kepercayaan anggota |
| **Akuntabilitas** | Setiap transaksi dapat dipertanggungjawabkan |
| **Pengawasan** | Memudahkan pengawasan oleh anggota |
| **Perencanaan** | Membantu perencanaan keuangan masa depan |
| **Efisiensi** | Mengidentifikasi pemborosan |

#### 1.3 Prinsip Transparansi Keuangan

| Prinsip | Deskripsi |
|---------|-----------|
| **Keterbukaan** | Semua anggota dapat melihat laporan |
| **Akurasi** | Data harus akurat dan dapat dipercaya |
| **Ketepatan Waktu** | Laporan disajikan tepat waktu |
| **Kelengkapan** | Semua transaksi tercatat |
| **Konsistensi** | Metode pencatatan konsisten |

#### 1.4 Siklus Manajemen Keuangan

```
📸 [Diagram: Siklus Manajemen Keuangan]
```

| Tahap | Deskripsi |
|-------|-----------|
| **Perencanaan** | Menyusun anggaran |
| **Pencatatan** | Mencatat setiap transaksi |
| **Pemantauan** | Memantau arus kas |
| **Pelaporan** | Membuat laporan keuangan |
| **Evaluasi** | Mengevaluasi kinerja keuangan |

### Bagian 4: Menambah Transaksi Pemasukan (20 Menit)

#### 4.1 Buka Form Tambah Transaksi

**Langkah 1: Klik "+ Tambah Transaksi"**
1. Klik tombol **"+ Tambah Transaksi"** di pojok kanan atas
2. Pilih jenis transaksi: **"Pemasukan"**

```
📸 [Screenshot: Pilih Jenis Transaksi]
```

#### 4.2 Isi Form Pemasukan

**Demo Trainer:**
1. Isi form dengan contoh pemasukan
2. Jelaskan setiap field
3. Simpan transaksi

**Praktik Peserta:**
Isi form dengan pemasukan nyata:

| Field | Deskripsi | Contoh | Wajib |
|-------|-----------|--------|-------|
| **Tanggal** | Tanggal transaksi | 10 Februari 2026 | ✅ |
| **Kategori** | Jenis pemasukan | Iuran Anggota | ✅ |
| **Jumlah** | Nominal uang | Rp 50.000 | ✅ |
| **Deskripsi** | Detail transaksi | Iuran bulan Februari | ✅ |
| **Sumber** | Sumber pemasukan | Ahmad Fauzi | ❌ |
| **Kegiatan Terkait** | Kegiatan (jika ada) | - | ❌ |
| **Bukti** | Upload bukti transfer | [Upload] | ❌ |

```
📸 [Screenshot: Form Pemasukan]
```

#### 4.3 Kategori Pemasukan

| Kategori | Deskripsi | Contoh |
|----------|-----------|--------|
| **Iuran Anggota** | Iuran rutin anggota | Iuran bulanan |
| **Donasi** | Donasi dari pihak luar | Donasi alumni |
| **Sponsorship** | Sponsorship kegiatan | Sponsorship event |
| **Penjualan** | Hasil penjualan | Penjualan merchandise |
| **Lainnya** | Pemasukan lainnya | Bunga bank |

#### 4.4 Tips Mengisi Form Pemasukan

**Jumlah:**
- Gunakan format yang benar
- Sertakan satuan (Rp)
- Contoh: Rp 50.000

**Deskripsi:**
- Jelaskan sumber pemasukan
- Sebutkan detail penting
- Contoh: "Iuran bulan Februari dari Ahmad Fauzi"

**Bukti:**
- Upload bukti transfer jika ada
- Pastikan bukti jelas terbaca
- Format: JPG, PNG, PDF

#### 4.5 Simpan Transaksi

**Langkah 1: Review Data**
1. Periksa kembali semua data
2. Pastikan jumlah benar

**Langkah 2: Simpan**
1. Klik tombol **"Simpan"**
2. Tunggu notifikasi **"Transaksi berhasil ditambahkan"**

```
📸 [Screenshot: Notifikasi Sukses]
```

**Langkah 3: Verifikasi**
1. Transaksi akan muncul di laporan
2. Saldo akan otomatis diperbarui
