# Quick Start Guide PPSDM KMITS
## Panduan Setup Awal dalam 15 Menit

---

## 🎯 Tujuan

Panduan ini akan membantu Anda memulai menggunakan PPSDM KMITS dalam waktu singkat. Setelah mengikuti panduan ini, Anda akan dapat:
- ✅ Login ke sistem
- ✅ Menghubungkan Google Sheets
- ✅ Menambahkan kegiatan pertama
- ✅ Memahami dasar navigasi

**Waktu yang dibutuhkan:** 15 menit

---

## 📋 Prasyarat

Sebelum memulai, pastikan Anda memiliki:

| Item | Status |
|------|--------|
| Akun Google (Gmail) | ☐ |
| Koneksi Internet | ☐ |
| Browser (Chrome/Edge/Firefox) | ☐ |
| Akun PPSDM KMITS | ☐ |

## 🚀 Langkah 1: Login ke Sistem (2 Menit)

### 1.1 Buka Website

1. Buka browser Anda
2. Ketik URL: `https://ppsdm-kmits.vercel.app`
3. Tekan Enter

```
📸 [Screenshot: Halaman Login]
```

### 1.2 Masukkan Kredensial

1. **Email:** Masukkan email yang terdaftar
2. **Password:** Masukkan password Anda
3. Klik tombol **"Masuk"**

```
📸 [Screenshot: Form Login]
```

### 1.3 Verifikasi (Jika Diperlukan)

Jika ini pertama kali login:
1. Periksa email Anda
2. Cari email dari PPSDM KMITS
3. Salin kode verifikasi
4. Masukkan kode di halaman login
5. Klik **"Verifikasi"**

```
📸 [Screenshot: Verifikasi Email]
```

✅ **Selesai!** Anda sekarang berada di Dashboard.

---

## 🔗 Langkah 2: Hubungkan Google Sheets (5 Menit)

### 2.1 Buka Pengaturan

1. Di sidebar kiri, klik menu **⚙️ Pengaturan**
2. Cari bagian **"Integrasi"**
3. Klik **"Google Sheets"**

```
📸 [Screenshot: Menu Pengaturan]
```

### 2.2 Hubungkan Akun Google

1. Klik tombol **"Hubungkan Google Sheets"**
2. Anda akan diarahkan ke halaman Google
3. Login dengan akun Google Anda

```
📸 [Screenshot: Tombol Hubungkan]
```

### 2.3 Berikan Izin Akses

1. Baca permintaan izin dengan teliti
2. Klik **"Allow"** atau **"Izinkan"**
3. Tunggu proses autentikasi selesai

```
📸 [Screenshot: Izin Google]
```

### 2.4 Pilih atau Buat Spreadsheet

**Opsi A: Gunakan Spreadsheet Baru**
1. Klik **"Buat Spreadsheet Baru"**
2. Beri nama: `PPSDM KMITS Data`
3. Klik **"Buat"**

**Opsi B: Gunakan Spreadsheet yang Ada**
1. Klik **"Pilih Spreadsheet"**
2. Pilih dari daftar spreadsheet Anda
3. Klik **"Pilih"**

```
📸 [Screenshot: Pilih Spreadsheet]
```

### 2.5 Konfirmasi Koneksi

1. Tunggu notifikasi **"Koneksi Berhasil"**
2. Periksa daftar sheet yang dibuat:
   - `Kegiatan`
   - `Keuangan`
   - `Anggota`
   - `Assessment`

```
📸 [Screenshot: Konfirmasi Koneksi]
```

✅ **Selesai!** Google Sheets sekarang terhubung.

---

## 📅 Langkah 3: Tambah Kegiatan Pertama (5 Menit)

### 3.1 Buka Menu Kegiatan

1. Di sidebar, klik menu **📅 Kegiatan**
2. Anda akan melihat daftar kegiatan (kosong untuk pertama kali)

```
📸 [Screenshot: Menu Kegiatan]
```

### 3.2 Klik Tombol Tambah

1. Klik tombol **"+ Tambah Kegiatan"** di pojok kanan atas
2. Form akan muncul

```
📸 [Screenshot: Tombol Tambah]
```

### 3.3 Isi Form Kegiatan

Isi informasi berikut:

| Field | Contoh | Wajib |
|-------|--------|-------|
| **Nama Kegiatan** | Rapat Mingguan | ✅ |
| **Tanggal** | 15 Februari 2026 | ✅ |
| **Waktu** | 19:00 - 21:00 | ✅ |
| **Lokasi** | Ruang Rapat A | ✅ |
| **Deskripsi** | Pembahasan program bulanan | ❌ |
| **Penanggung Jawab** | Budi Santoso | ✅ |

```
📸 [Screenshot: Form Kegiatan]
```

### 3.4 Simpan Kegiatan

1. Periksa kembali data yang diinput
2. Klik tombol **"Simpan"**
3. Tunggu notifikasi **"Kegiatan berhasil ditambahkan"**

```
📸 [Screenshot: Notifikasi Sukses]
```

### 3.5 Verifikasi di Google Sheets

1. Buka Google Sheets Anda
2. Buka sheet `Kegiatan`
3. Pastikan kegiatan yang baru ditambahkan muncul

```
📸 [Screenshot: Data di Sheets]
```

✅ **Selesai!** Kegiatan pertama Anda berhasil ditambahkan.

## 🆘 Butuh Bantuan?

### Masalah Umum

**Q: Tidak bisa login?**
- Pastikan email dan password benar
- Cek koneksi internet
- Reset password jika lupa

**Q: Google Sheets tidak terhubung?**
- Pastikan izin diberikan
- Coba refresh halaman
- Hubungkan ulang dari pengaturan

**Q: Data tidak muncul di Sheets?**
- Tunggu 1-2 menit untuk sinkronisasi
- Klik "Sinkronisasi Sekarang" di pengaturan
- Periksa koneksi internet
