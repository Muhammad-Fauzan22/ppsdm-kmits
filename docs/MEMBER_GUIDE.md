## 📊 Mengikuti Assessment

### Melihat Assessment yang Tersedia

1. Klik menu **📊 Assessment** di sidebar
2. Daftar assessment akan ditampilkan

```
📸 [Screenshot: Daftar Assessment Member]
```

### Status Assessment

| Status | Deskripsi |
|--------|-----------|
| **Belum Diisi** | Anda belum mengisi assessment |
| **Sedang Diisi** | Anda sedang mengisi (draft) |
| **Selesai** | Anda sudah menyelesaikan assessment |
| **Kadaluarsa** | Waktu pengisian sudah habis |

### Mengisi Assessment

**Langkah 1: Buka Assessment**
1. Klik assessment yang ingin diisi
2. Baca instruksi dengan teliti

```
📸 [Screenshot: Detail Assessment]
```

**Langkah 2: Mulai Mengisi**
1. Klik tombol **"Mulai Mengisi"**
2. Pertanyaan akan muncul satu per satu

```
📸 [Screenshot: Mulai Assessment]
```

**Langkah 3: Jawab Pertanyaan**

**Tipe Pilihan Ganda:**
1. Baca pertanyaan
2. Pilih jawaban yang benar
3. Klik **"Lanjut"**

```
📸 [Screenshot: Pilihan Ganda]
```

**Tipe Skala 1-5:**
1. Baca pertanyaan
2. Pilih skala (1 = Sangat Tidak Setuju, 5 = Sangat Setuju)
3. Klik **"Lanjut"**

```
📸 [Screenshot: Skala 1-5]
```

**Tipe Essay:**
1. Baca pertanyaan
2. Ketik jawaban Anda
3. Klik **"Lanjut"**

```
📸 [Screenshot: Essay]
```

**Langkah 4: Review Jawaban**
1. Setelah semua pertanyaan dijawab
2. Review jawaban Anda
3. Klik **"Kirim"**

```
📸 [Screenshot: Review Jawaban]
```

**Langkah 5: Konfirmasi**
1. Konfirmasi pengiriman
2. Tunggu notifikasi **"Assessment berhasil dikirim"**

```
📸 [Screenshot: Konfirmasi Kirim]
```

### Menyimpan Draft

Jika belum selesai mengisi:

1. Klik **"Simpan Draft"**
2. Jawaban akan tersimpan
3. Bisa dilanjutkan nanti

```
📸 [Screenshot: Simpan Draft]
```

### Melihat Hasil Assessment

Jika admin sudah mempublikasikan hasil:

1. Buka menu **📊 Assessment**
2. Klik assessment yang sudah selesai
3. Hasil akan ditampilkan

```
📸 [Screenshot: Hasil Assessment]
```

## 💡 Tips dan Best Practices

### Untuk Kegiatan

1. **Cek Kegiatan Secara Rutin**
   - Buka menu Kegiatan setiap hari
   - Daftar kegiatan yang relevan
   - Catat tanggal penting

2. **Baca Detail Kegiatan dengan Teliti**
   - Perhatikan tanggal dan waktu
   - Cek lokasi kegiatan
   - Baca persyaratan kegiatan

3. **Datang Tepat Waktu**
   - Catat waktu kegiatan
   - Siapkan diri sebelumnya
   - Beri tahu jika tidak bisa hadir

### Untuk Assessment

1. **Isi Assessment dengan Jujur**
   - Jawab sesuai kondisi nyata
   - Jangan terburu-buru
   - Baca pertanyaan dengan teliti

2. **Selesaikan Sebelum Deadline**
   - Cek deadline assessment
   - Sisihkan waktu untuk mengisi
   - Jangan menunggu menit terakhir

3. **Gunakan Draft jika Perlu**
   - Simpan draft jika belum selesai
   - Lanjutkan nanti
   - Jangan lupa mengirim sebelum deadline

### Untuk Knowledge Sharing

1. **Baca Artikel Secara Rutin**
   - Luangkan waktu untuk membaca
   - Pelajari hal baru
   - Terapkan pengetahuan yang didapat

2. **Berikan Komentar yang Konstruktif**
   - Sampaikan pendapat dengan sopan
   - Berikan masukan yang berguna
   - Hormati pendapat orang lain

3. **Simpan Artikel Penting**
   - Gunakan fitur simpan
   - Baca kembali nanti
   - Bagikan ke teman

### Untuk Keamanan

1. **Jaga Kerahasiaan Akun**
   - Jangan berbagi password
   - Logout setelah selesai
   - Gunakan password yang kuat

2. **Laporkan Masalah**
   - Beritahu admin jika ada error
   - Berikan detail masalah
   - Sertakan screenshot jika perlu

3. **Perbarui Profil**
   - Update informasi profil
   - Ganti password secara berkala
   - Periksa pengaturan notifikasi
